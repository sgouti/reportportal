How this search works
1
Keyword matching
Finds exact matches on error class names, error codes, and file paths. Best for specific error strings like "502" or "AssertionError".
2
Meaning-based search
Understands the intent behind your query — finds failures that mean the same thing even if worded differently. "502 error" and "Bad Gateway" match the same results.
3
Combined ranking
Both scores are merged — you get the precision of keyword search plus the flexibility of meaning-based search in one ranked list.
